# 20组多用途参考 × 多人教学实测 · v1.6.0

[简体中文](teaching-gallery.md) · [English](teaching-gallery_EN.md) · [返回 README](../README.md)

全部案例均使用身份、服装、场景、配饰和风格参考，并组合双人或三人。场景与配饰素材各承担多个用途；20组另加布局参考。原图与最终图均由本机 ComfyUI 真实生成，ImageGen 仅提供服装、空场景和配饰素材。原始画面为1536×864，教学合成为3840×2160；本页为便于浏览的2560×1440预览。女性身份统一采用同一张用户提供的参考，各组服装、男性人物、场景和表现风格有所变化。

![20组真实成图总览](images/teaching-v160/overview.jpg)

## 参数与复现

2026-10-09，RTX 5090 Laptop 24GB，ComfyUI 0.36.0 / 前端1.53.6。Qwen Image 2.1 + Viggle Turbo v0.3 r128，Euler、作者动态Sigma、BasicGuider、6步，无负向CFG，不叠加AnyAngle LoRA。每组实际送入6或7张图，参考预算384；这组测试是多人多参考的实际案例，不是速度对比基准。

[Turbo GUI工作流](../workflows/AnyAngle-Studio-Qwen21-ViggleTurbo6.json) · [API模板](../workflows/AnyAngle-Studio-Qwen21-ViggleTurbo6-API.json) · [素材库操作与模型来源](reference-library.md) · [逐例图号、提示词与哈希](teaching-gallery-validation.json)。模板不含本页素材或有效本机快照，需自行添加参考并应用。20个本机GUI工作流已由真实前端编译，20个便携场景ZIP完成实际导入验证。

人偶和高斯可以调整机位；从照片直接提取的POSE、DA3深度、Canny是二维图。19/20组不传引导图，环境作为首图；20组增加布局用途。多用途与人物目标通过图像和提示词引导，不是区域硬遮罩或精确身份锁定，以下保留实际偏差和修订说明。
