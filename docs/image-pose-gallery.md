# 图片姿势库

图片姿势库接入 [Anhao 中文姿势图库](https://github.com/anhao/ai-pose-gallery-zh) 的 **288 个动作组、1439 个实际视角、2878 张原图及缩略图**。固定来源版本为 `072a3690af6e7e0011abbe0fa1ccc08939fbb47d`。一个动作组通常包含正面、侧面、斜侧、俯视和仰视；`full_sexy_P018` 原库没有仰视图，因此只有四个视角，界面不会补造第五张。

它与原有可编辑骨骼动作共用搜索入口，但图片本身仍是二维参考。可以直接将其作为动作参考，也可以提取、修正可见关节，再复制到三维人偶。

## 安装与离线使用

在 Studio 左侧页签下点击「打开姿势库 · 搜索 / 导入 / 收藏」，展开「图片姿势库 · 导入、搜索预设与收藏夹」。无需先创建人偶；原图重建、静态引导与仅参考模式也能打开图库。只有复制或保存可编辑骨骼时需要人偶。

1. 点击「导入图片图库 ZIP」，选择完整素材包；或点击「导入图片图库目录」，选择包含 `data/`、`img/`、`thumbs/` 的完整原始目录。不要只选择缩略图文件夹。
2. 等待上传和逐图校验完成。成功后列表显示动作组，详情中切换各实际视角。
3. 导入后搜索、浏览、收藏和使用参考都读取本机文件，不需要访问原站。资料保存在 `ComfyUI/input/anyangle_studio/pose_gallery/`；原有骨骼姿势库单独保存，不会被替换。

配套完整素材包：[下载 ZIP](https://github.com/T8mars/Comfyui-Qwen-Image-2.1-MultiAngle-T8/releases/download/v1.8.0/AnyAngle-AI-Pose-Gallery-288-groups-1439-views.zip)，693,904,383 字节（约 662 MiB）。[v1.8.0 Release](https://github.com/T8mars/Comfyui-Qwen-Image-2.1-MultiAngle-T8/releases/tag/v1.8.0) 同时提供校验清单及来源声明。

```text
SHA256: 5e893d3299dd27966019816a2ff87419d5e99375a52f5dc8757adc3287e07503
```

「导入任务 / 继续导入」可以取消、重新选择原文件继续上传，或校验已上传的完整文件重试。继续上传时需选择同名目录或 ZIP；这是重新上传所选文件，不是从文件的断点字节续传。导入失败或取消不会用半份目录替换已发布的图库。

「删除上传临时文件」只清除该任务上传的暂存文件；「清理导出与无引用缓存」清理导出包和未被图库引用的图片缓存。两者都保留已导入图库和已应用到场景的受管素材。

## 快速找动作

搜索支持中文名、原名、动作编号、自定义标签，以及该固定中文图库名称的全拼、首字母。常用动作有别名，例如「举手 / 举臂 / 抬手」「叉腰 / 扶腰」。重命名或新导入的任意中文标题不会自动生成全套拼音，仍可按文字与标签搜索。

| 输入或筛选 | 查找方式 |
| --- | --- |
| `双人 牵手 侧面` | 三个条件同时满足，只列出具有匹配侧面视角的动作组 |
| `举手`、`jushou` | 搜索举手动作词族 |
| `full_single_P019_front` | 精确定位动作及实际视角 |
| 类型「图片姿势参考」 | 暂时排除可编辑骨骼动作和多人编排 |
| 人数、全身 / 上半身、视角、收藏夹 | 与搜索词叠加筛选 |

多个关键词使用 AND；同一动作的别名归为同一词族。短拼音可能有多义，例如 `zz` 可匹配站姿或坐姿，想精确查找时使用中文或全拼。无结果时界面给出放宽条件的建议，不会偷偷取消筛选。筛选标签可以单独移除；最近应用、收藏优先和每页 24 张卡片方便反复挑选。

默认按相关度排序：动作名称直接命中优先于标签与宽泛分类，动作查询同分时较短标题先显示；精确名称和完整编号仍优先。「收藏优先」「最近应用」会优先采用你选择的顺序，搜索和筛选条件继续保留。比如 `坐姿 抱膝 后仰` 能找到「抱单膝坐・背部后仰」，不会把单膝跪混入抱膝结果。

常用条件可以「保存当前搜索」，之后更新、改名或删除。收藏夹可以新建、改名、删除，并在详情中把动作加入或移出当前收藏夹。「导出预设与收藏夹」生成 JSON，「导入预设与收藏夹」按 ID 合并，同 ID 采用导入值。它只带设置，不含图片；跨机器迁移图片使用图库 ZIP。

动作组可收藏、改名、编辑标签或隐藏；在「已隐藏的图片」中可恢复。「导出此动作组」和「导出全部图片图库」包含原图、缩略图、来源及个人设置。导入完整便携包时保留本机已有同 ID 的个人编辑、预设和收藏夹，补入本机没有的条目。

## 三种调用方式

### 作为动作参考

选择动作和视角，在「动作参考用于」选择整个画面、指定人物或当前所选人物，点击「作为动作参考」。图片会加入素材库，自动使用「动作 / 姿态」用途，不会把线稿人物当成身份参考。可同时保留人脸、服装、场景和风格素材。

这个按钮保留当前创作方式与模型选择。纯文本模式不发送图片，需要手动切换为多图参考模式。建议多人编码节点使用 `studio-plus-input`，自动合并动作用途和自己的提示词；`input-full` 仍完全使用你填写的全文，需要自行描述图号、动作和目标。

多图用途属于模型的软参考。真实举臂样例中，把线稿放在身份、服装、背景后面时，模型仍生成了放下手臂的站姿；在「输出画幅参考」中把动作图设为首图后仅跟随了一侧手臂；提取为静态 POSE 引导后才跟随双臂上举。对动作要求明确时，优先核对骨架并使用 POSE 引导，勿将“图片已发送”理解为“模型一定照做”。首图调整也会改变输出画幅。[实测记录](image-pose-gallery-validation.md)。

### 使用静态 POSE 引导

点击「提取 POSE / 复制到人偶」，核对骨架后选择「使用预览中的静态 POSE 引导」。它采用这个视角的二维骨架并切为 Qwen 底模 + 构图引导；保留当前来源图、人物身份和三维场景。

静态骨架不随相机旋转。要换图库的已知视角，选择另一张源图；要自由调整机位，需先复制到可编辑人偶。

### 复制到指定人偶

先切换可编辑人偶场景，再提取或修正关节。为每个检测人物明确选择「不复制此人」「新增人偶」或某个现有人物，然后点击「确认复制到指定人物」。同一人偶不能接收两套动作，锁定和隐藏人物不会作为可编辑目标。

默认只复制可见身体关节的方向，保留身份、体型、站位和相机；没有检测到的肢体维持当前姿势。二维图无法提供可靠的肢体前后深度，复制后可继续手调。确认复制会启用 Qwen 底模的三维人偶 POSE 引导。

只有勾选「匹配来源横向站位、人物大小并重新取景」才调整相应站位、大小和机位。涉及接触关系时需明确勾选允许解除。多人复制使用一次撤销记录；中途失败会恢复复制前场景。

## 线稿检出失败与手动修正

DWPose 的人体检测器不保证识别图库线稿。提取窗口提供「线稿未检出或骨架不准？框选人物 / 修正关节」：

1. 在框选模式拖出每个人物的区域，再点击「按框提取姿势」。单人图也可用「整张图作为单人区域」。自动检测按左至右编号，框选检测按画框顺序编号；重新检测后重新确认人物映射。
2. 切换「修正关节（点击）」，选择人物和关节，在原图上点击可见位置。可「新增标注人物」或「清除此关节」。只标看得见的关节，不用猜画外四肢。
3. 对照原图检查肩、肘、腕及左右腿，再应用静态骨架或复制人偶。复制人偶至少需要左右肩和颈部；手工身体点不等于完整的手指、面部或三维骨骼。

本机真实抽样结果：举臂、半身手势和重叠双人三张线稿，自动人体检测均未检出人物；显式框选后，举臂图取得完整的 14 个身体关节，半身仍有漏点，重叠双人存在串关节。因而框选结果仍须核对，不将「检测成功」等同于动作准确。

## 两种批量不要混淆

| 批量方式 | 每个任务改变什么 | 适合场景 |
| --- | --- | --- |
| 图片详情的「按图库视角批量」 | 每个任务使用一张已经存在的图库视角图 | 一次尝试多张动作参考、正侧面参考 |
| 原有「姿势库已选动作 × 以下机位」 | 对可编辑人偶动作渲染不同三维机位 | 骨骼动作与 45°、−45°、90° 等相机组合 |

图库视角批量先勾选实际视角、加入列表，再运行。默认不附加当前构图引导，也可以选择保留；其他素材与文字随任务冻结。可仅保存场景快照，或从 ComfyUI 节点打开 Studio 后保存并入队。纯独立工作台不能直接入 ComfyUI 队列。

每项快照和回执记录实际视角 ID、来源文件哈希和转存 PNG 的哈希；重新编码 PNG 后文件哈希可能不同，实际像素保持。停止只阻止后续任务，已经提交的生成任务保留，结束后恢复编辑草稿。超过建议的 10 张参考会提示，图片仍完整保留；显存与最终遵循程度需按模型和预算检查。

## 模型、来源与验证范围

浏览、搜索、导入导出、直接添加图片参考及手工标点无需新增模型。自动或框选提取复用 [DWPose ONNX 权重](https://huggingface.co/yzd-v/DWPose/tree/1a7144101628d69ee7a3768d1ee3a094070dc388)：`yolox_l.onnx` 与 `dw-ll_ucoco_384.onnx`，合计约 351 MB。优先读取：

```text
ComfyUI/custom_nodes/comfyui_controlnet_aux/ckpts/yzd-v/DWPose/
```

若没有这两份文件，首次点击提取时下载至 `<AnyAngle节点目录>/.local/dwpose/`；可事先把相同权重放在那里以便离线使用。推理使用 ComfyUI 的 Python 环境及 `onnxruntime`。最终生成继续使用已有 Qwen Image 2.1 主模型、文本编码器与 VAE，详见 [模型清单](../README.md#按功能准备模型)。
